# Knowledge index

This index covers maintained pipeline knowledge through 2026-08-22. The
2026-08-07 through 2026-08-22 maintenance window was reconciled with the older
skill guidance; rules are organized by decision boundary rather than by run or
incident.

| Need | Load | Useful search terms |
| --- | --- | --- |
| Decide whether work is generation or editing | [Evidence and route selection](evidence-and-routing.md) | source authority, final reference, static, dynamic |
| Reconstruct an asset from video or tutorial evidence | [From-zero generation](generation.md) | Q-Gate, stage isolation, operation fidelity, anti-collapse |
| Modify an existing project or replace selected content | [Existing-asset editing](editing.md) | mutation scope, envelope, material graph, before/after |
| Render, frame, expose, animate, or validate output | [Rendering, visual QA, and dynamics](rendering-and-dynamics.md) | foreground, motion envelope, simulation, encoding |
| Run distributed work, paid calls, retrieval, or publication | [Operations and knowledge lifecycle](operations-and-knowledge.md) | idempotency, prepared bundle, failure class, promotion |

Load only the route-specific document plus the shared document needed for the
current decision. Each maintained rule states when it applies, the decision it
changes, how to verify it, and search terms.

Promote new knowledge only when it is either a cross-task invariant or has
survived an unrelated holdout. Keep task identifiers, machine paths, private
endpoints, credentials, raw traces, run histories, and evaluation outputs out
of this knowledge package.
